Clashtest Mod Conflict SaaS

執行摘要 Executive Summary

主題 Theme

Clashtest 是面向遊戲模組玩家與模組創作者的 Micro-SaaS 平台。 使用者上傳 loadorder.txt 或 plugins.txt 後，系統會偵測模組衝突類型、風險等級、排序問題與相依性異常。

目的 Purpose

解決模組安裝後常見的閃退、覆寫、排序錯誤與相依性衝突。 平台不生成 AI 補丁，而是輸出 衝突分析報告、風險分級與 Load Order 建議。

核心微服務架構 Core Features

1. 雲端輕量化分析

上傳 KB 級設定檔後，系統分析模組排序、相依性、覆寫關係與風險分布。 使用者不需要在本機安裝額外工具。

2. 衝突模組類型偵測

偵測 Skeleton Conflict、Script Override、Dialogue Conflict、Asset Conflict 與 Load Order Conflict，並輸出建議處理方向。

商業模式 Business Model

  • ▪ 免費版：每月 3 次基礎衝突分析。
  • ▪ 進階版：完整衝突報告、風險分級、Load Order 建議。
  • ▪ 專業版：提供歷史紀錄、雲端備份、模組組合比較。

未來展望 Vision

  • ▪ 建立大型模組衝突資料庫。
  • ▪ 支援多遊戲模組生態。
  • ▪ 提供創作者相容性檢查 API。
  • ▪ 導入模組風險評分與安裝前預測。

報告輸出

本系統輸出 Conflict_Report.pdf，不生成 AI 補丁，避免誤修改使用者模組環境。 報告內容包含衝突類型、風險等級、相關模組與建議處理方式。
